ARCHITECTURAL DEPLOYMENT DECISION & SCALABILITY INQUIRY:
1. Acceptable Lookup Response Time: Sub-microsecond (< 1.0 us per lookup).
2. Chosen Production Map: LinkedHashMap.
   Defense: Pharmacists query stock hundreds of times every hour.
   LinkedHashMap provides O(1) hash lookup (~4-6 ms for 100k queries) AND
   naturally yields the daily Insertion-Order report in O(n) time.
   The Code-Order report runs only ONCE every evening, taking ~15 ms to sort.
3. Why Hashtable is Obsolete:
   - Hashtable synchronizes EVERY method, creating severe thread bottlenecks.
   - Disallows null keys and null values.
   - Modern code uses ConcurrentHashMap for concurrency and LinkedHashMap/HashMap otherwise.
